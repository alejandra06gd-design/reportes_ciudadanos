# \# CIVIC APP – Reportes Ciudadanos

# 

# Aplicación móvil desarrollada con Flutter que permite a los ciudadanos registrar, consultar y realizar seguimiento de reportes sobre problemas o incidencias de su comunidad.

# 

# CIVIC APP busca facilitar la comunicación ciudadana mediante una plataforma digital accesible, permitiendo compartir información, fotografías y ubicaciones para dar visibilidad a las necesidades de la comunidad.

# 

# \## Funcionalidades principales

# 

# \- Registro e inicio de sesión de usuarios.

# \- Autenticación mediante correo electrónico y Google.

# \- Creación de reportes ciudadanos con fotografías.

# \- Registro de ubicación mediante GPS.

# \- Visualización de reportes comunitarios.

# \- Consulta de reportes en un mapa.

# \- Seguimiento del estado de los reportes.

# \- Notificaciones sobre actualizaciones.

# \- Edición y eliminación de reportes pendientes.

# \- Perfil de usuario.

# 

# \## Tecnologías utilizadas

# 

# | Tecnología | Uso |

# |---|---|

# | Flutter | Desarrollo de la aplicación móvil |

# | Dart | Lenguaje de programación |

# | Supabase | Backend y autenticación |

# | PostgreSQL | Base de datos |

# | Supabase Storage | Almacenamiento de imágenes |

# | OpenStreetMap | Visualización cartográfica |

# | Git y GitHub | Control de versiones |

# | GitHub Actions | Integración continua (CI) |

# 

# \## Instalación

# 

# 1\. Acceder a la sección \[Releases](https://github.com/alejandra06gd-design/reportes\_ciudadanos/releases).

# 2\. Descargar la versión más reciente del archivo APK.

# 3\. Transferir el archivo al dispositivo Android.

# 4\. Abrir el APK y autorizar la instalación si Android lo solicita.

# 5\. Instalar y ejecutar CIVIC APP.

#
